# BAKEWIRE

Independent Lithuanian weekly digital magazine covering marketing, business, AI and technology.

**Brand:** BAKEWIRE — Fresh news. Sharp takes.

**Editorial source:** Šviežios kaip bandelės · 2026-11-21 issue.

This repository hosts the production-ready static website and its editable content. Cloudflare Pages is the intended deployment target. The site is built without paid runtime dependencies.

## Deployment
Connect this repository to Cloudflare Pages, with production branch `main`. If static files are committed at repository root, use the root as output directory and no build command. Domain `bakewire.com` can be connected after DNS registration.

## Editorial policy
All published editorial imagery is explicitly labelled as illustration where appropriate. Linked sources are retained with each article.
